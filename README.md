# 🌿 Tarun Kirana Store - WhatsApp Ordering Web App

तारुन किराना स्टोर (Tarun Kirana Store) एक आधुनिक, तेज़ और मोबाइल-फ्रेंडली सिंगल-पेज वेब एप्लिकेशन है। इसके ज़रिए स्थानीय ग्राहक आपकी दुकान के किराना सामान, डेयरी प्रोडक्ट्स और स्नैक्स को आसानी से ब्राउज़ कर सकते हैं, उन्हें कार्ट में जोड़ सकते हैं और सीधे **WhatsApp** के माध्यम से ऑर्डर भेज सकते हैं।

---

## ✨ मुख्य विशेषताएँ (Features)

* **📱 रेस्पॉन्सिव डिज़ाइन:** मोबाइल, टैबलेट और कंप्यूटर सभी स्क्रीन पर एकदम सटीक और सुंदर दिखता है।
* **🛒 स्मार्ट कार्ट सिस्टम (Cart System):** बिना किसी डेटाबेस के, ब्राउज़र में ही प्रोडक्ट्स को जोड़ें, घटाएं या हटाएं।
* **🔍 लाइव सर्च बार (Live Search):** ग्राहक किसी भी सामान (जैसे: Atta, Dal, Soap) को तुरंत ढूंढ सकते हैं।
* **🗂️ कैटेगरी फ़िल्टर (Category Filter):** सामानों को अलग-अलग कैटेगरी (जैसे: चवाल, तेल और घी, मसाले) के हिसाब से देखना बेहद आसान है।
* **💬 डायरेक्ट व्हाट्सएप ऑर्डर (WhatsApp Ordering):** ग्राहक का नाम, नंबर और एड्रेस के साथ पूरा ऑर्डर फ़ॉर्मेट होकर सीधे आपके व्हाट्सएप नंबर पर पहुंच जाता है।
* **⚡ बिना इमेज के भी रेडी:** अगर आपके पास प्रोडक्ट्स की तस्वीरें नहीं हैं, तो यह खूबसूरत इमोजी (Emojis) का इस्तेमाल करके प्रोफेशनल लुक देता है।
